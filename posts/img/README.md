## Tips

- Use a mobile viewport (e.g. Chrome DevTools → iPhone 14) so the screenshots match the actual donor experience.
- Crop to the visible card; leave a little padding around it.
- Keep each PNG under ~300 KB so GitHub and LinkedIn previews load fast.
